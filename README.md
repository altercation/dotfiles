# ES dotfiles

Ethan Schoonover's dotfiles

* email es@ethanschoonover.com
* github: [altercation](https://github.com/altercation/)
* web: [ethanschoonover.com](https://ethanschoonover.com)
* bsky: [ethanschoonover.com](https://bsky.app/profile/ethanschoonover.com)

Managed with [chezmoi](https://www.chezmoi.io), so filenames are in chezmoi's [remapped filename format](https://www.chezmoi.io/user-guide/frequently-asked-questions/design/#why-does-chezmoi-use-weird-filenames).

## Files of note:

* [system-deployment](bin/executable_system-deployment) - my primary system deployment script for a new mac
* [system-defaults](bin/executable_system-defaults) - baseline defaults for a new mac
* [karabiner.edn](private_dot_config/private_karabiner/karabiner.edn) - my [karabiner](https://karabiner-elements.pqrs.org) configuration managed by [goku](https://github.com/yqrashawn/GokuRakuJoudo) and designed around current window manager of choice, [omniwm](https://omniwm.app).
* [help.pdf](private_dot_config/private_karabiner/help.pdf) - a visual overview of my primary keymap
